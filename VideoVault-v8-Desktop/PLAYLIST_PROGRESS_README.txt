VideoVault Playlist Progress Update

Shows current video progress, real backend processing stage, and overall playlist percentage.
Percentages are reported by YoutubeExplode/TikTok stream downloads. FFmpeg conversion/merge does not report granular progress and can remain at 85-90% until complete.
This is not a measured speed/ETA indicator.

Build on Windows using BUILD_EXE.cmd. Copy ffmpeg.exe to bin as before.
