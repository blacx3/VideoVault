VideoVault V8 + yt-dlp: Instagram Preview

The original YouTube/Shorts, TikTok, playlist and Smart Audio engines remain unchanged.
This version adds Instagram public Reels and single-video posts through yt-dlp.

INSTALL
1. Download yt-dlp.exe (Windows x64 standalone) from the official GitHub releases:
   https://github.com/yt-dlp/yt-dlp/releases/latest
2. Place yt-dlp.exe in the bin folder alongside ffmpeg.exe.
3. Run BUILD_EXE.cmd. Keep bin/ and wwwroot/ with the published executable.
4. Paste a public Instagram Reel or video post URL. Choose MP4 or MP3.

NOTE: No separate Python installation is required for the Windows standalone yt-dlp.exe.
Some Instagram posts require login or are unavailable; no login/cookie bypass is implemented.
Instagram photo and carousel support are NOT included in this preview.
YouTube/TikTok still use their existing engines; yt-dlp is used for Instagram only.
The yt-dlp.exe file is not included in this source ZIP; download it directly from its official release.
Bundled standalone yt-dlp builds may have GPLv3+ licensing obligations; review the upstream license before redistributing.
This build has not been compiled or tested on Windows in this environment.
